
# TrendPulse — Part 2: NumPy and Pandas Data Wrangling

## Project Overview
This part focuses on combining, cleaning, transforming, and analyzing YouTube trending video datasets from the US, UK, and India.

## Tools Used
- Python
- NumPy
- Pandas
- Google Colab

## Tasks Completed
1. Loaded datasets from three countries.
2. Created NumPy arrays and performed array operations.
3. Combined country datasets using Pandas.
4. Handled missing values and duplicates.
5. Converted date and numeric columns.
6. Merged video categories.
7. Filtered and sorted video records.
8. Performed grouping and aggregation.
9. Analyzed trending lifespan and channel performance.
10. Created engagement scores.

## Output Files
- part2_cleaned_dataset.csv
- category_summary.csv
- country_summary.csv
- trending_lifespan.csv
- channel_summary.csv
